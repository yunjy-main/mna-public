Two-device complete bidirectional Softplus and SOA model

Parameter scaling, monotonic degradation, measured I-V, eight SOA envelopes, arbitrary-x evaluation.

Common model

F(v,x)=softplus(a1(x)(v-c1(x)))/(r1(x)a1(x))-softplus(a2(x)(c2(x)-v))/(r2(x)a2(x))
I0(v,x)=F(v,x)-F(0,x)
g0(v,x)=sigmoid(a1(x)(v-c1(x)))/r1(x)+sigmoid(a2(x)(c2(x)-v))/r2(x)>0
SOA: M(x)=s*C*(x/x0)^p; worst/best share p and each anchors one residual extreme.
