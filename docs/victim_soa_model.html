Victim SOA Model

Silicided FET terminal Vfail과 gate-oxide breakdown을 분리한 victim SOA. Stack 전체 terminal stress와 각 개별 FET의 VGS/VGD/VGB oxide stress를 독립적으로 검사한다.

1. SOA 구조

A. Stack terminal SOA

Uterm = |VDS_stack| / Vfail(device_class, topology) PASS : Uterm < 1 FAIL : Uterm >= 1

`1stk_1rx`, `2stk_2rx`, `2stk_1rx`는 연속 변수가 아니라 물리적 topology이므로 lookup table로 사용한다.

B. Gate oxide SOA

VGS = VG - VS VGD = VG - VD VGB = VG - VB NFET inversion: Uinv = max(VGS,VGD,VGB,0) / Vinv NFET accumulation: Uacc = max(-VGS,-VGD,-VGB,0) / Vacc PFET inversion: Uinv = max(-VGS,-VGD,-VGB,0) / Vinv PFET accumulation: Uacc = max(VGS,VGD,VGB,0) / Vacc Uoverall = max(Uterm, Uinv, Uacc)
EGU NFET inversion의 원문 `EGU > -6.8 V`는 polarity상 모순이 있어 이 모델에서는 +6.8 V로 해석했습니다. PFET SG inversion의 `SG ≤ 3.3 V`도 −3.3 V로 해석했습니다.

PASS
2-stack 적용 원칙 1) Vfail lookup: 전체 stack의 external VDS에 적용 2) Gate oxide: stack 내부의 각 FET에 별도 적용 - upper FET: VG_upper, VS_upper, VD_upper, VB_upper - lower FET: VG_lower, VS_lower, VD_lower, VB_lower 3) center node가 floating이면 transient MNA node voltage로 각 FET의 VGS/VGD/VGB를 계산해야 함 4) stack terminal PASS라도 개별 oxide rule이 먼저 FAIL할 수 있음
