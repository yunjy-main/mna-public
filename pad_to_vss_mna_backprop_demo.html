PAD → VSS 단일 경로: 선형 MNA + Backpropagation 예제

목적: PAD에 +1 A를 forcing하고 VSS를 ground로 둔 toy ESD network에서 up diode area A, clamp area C, rail width W를 연속값으로 최적화하는 전체 흐름.

1. 회로 구조와 전류 경로

2. 설정값

Initial A, C, W
2.0, 2.0, 2.0
Forced current
1.0 A
Ground
VSS = 0 V
Victim SOA
VPAD ≤ 4.0 V
Up diode
Von=0.7 V, Ron=2/A Ω
Clamp
Von=1.5 V, Ron=3/C Ω
Rail
R=1/W Ω
Optimizer
Adam, lr=0.02

최종 연속해

A=3.2576 C=3.9897 W=2.3035 Vpad=4.000007 V

단일 initial condition의 continuous optimization 결과이므로 최종해는 1개입니다.

3. 선형 MNA 식

Unknowns: V = [V_P, V_U, V_C]^T g_D = A/2, g_R = W, g_C = C/3 [ g_D -g_D 0 ] [V_P] [ I + g_D·Von_D ] [ -g_D g_D+g_R -g_R ] [V_U] = [-g_D·Von_D ] [ 0 -g_R g_R+g_C ] [V_C] [ g_C·Von_C ]

이 toy 회로는 직렬 경로이므로 해가 간단히 Vpad = 2.2 + 2/A + 3/C + 1/W로 정리됩니다.

4. Loss와 gradient 흐름

h = V_PAD - Vfail Loss = A + C + W + μ · softplus(β·h)/β μ = 10.61, β = 50.0 Backprop: A,C,W → g_D,g_C,g_R → MNA solve → V_PAD → Loss Loss gradient → A,C,W update

softplus는 hard fail/pass의 계단형 판정을 부드럽게 만든 것입니다. 실제 sign-off 판정은 hard condition Vpad ≤ Vfail로 다시 확인합니다.
