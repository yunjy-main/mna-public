4. Table notes

최신 iteration이 가장 위에 표시됩니다. Radar와 gauge는 최종 iteration 기준입니다. A/C/R window rule은 projection이 아니라 violation penalty와 hard pass/fail 판정으로 처리됩니다.

Area/Resistance position: Apos = (A - Amin) / (Amax - Amin) Cpos = (C - Cmin) / (Cmax - Cmin) Rpos = (R - Rmin) / (Rmax - Rmin) SOA usage: usage = stress / limit 100% = boundary >100% = fail
