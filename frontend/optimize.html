4. Table notes

    
최신 iteration이 가장 위에 표시됩니다. Radar와 gauge는 최종 iteration 기준입니다.
x1/x2/L window rule은 projection이 아니라 violation penalty와 hard pass/fail 판정으로 처리됩니다(창립 rule 비대칭: min=가혹 FAIL, max=준-rule).
position = (값 − min) / (max − min) · SOA usage = stress/limit, 100% = boundary, >100% = fail.
victim SOA는 U_overall = max(NMOS/PMOS terminal·oxide) — SG NFET/PFET, topology 선택형. corner는 worst/best 양쪽 비관값(D3).
